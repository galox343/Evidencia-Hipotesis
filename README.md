# Evidencia-Hipotesis
## Hipótesis del proyecto integrador

Se planteo la implementación del sistema de monitorio de residuos, mediante el uso de un microcontrolador ESP32, sensores y una aplicación móvil, permitirá mejorar el monitoreo y la gestión de los residuos reciclables, al proporcionar información sobre el nivel de llenado y el peso de los contenedores. Esto facilitará la identificación de los contenedores que requieren recolección, contribuirá a optimizar las rutas de recolección y ayudará a reducir el desbordamiento de residuos, promoviendo una gestión más eficiente y sustentable.
